# Квазар — ERP для малого бизнеса (открытая бета)

Квазар — коробочная ERP-система: склад, закупки, продажи (включая
цифровые товары с автоотправкой кодов), производство, CRM с канбаном,
управленческий учёт с двойной записью, ИИ-ассистент и интеграции
(эквайринг, маркетплейсы, Telegram). Работает целиком на вашем
компьютере — данные никуда не уходят.

**Статус: открытая бета.** Продукт активно развивается, возможны
ошибки — о них рассказывайте в [Issues](../../issues).

## Установка (Windows)

**Требования:** Windows 10 21H2+ или Windows 11 (x64), оперативная
память 8+ ГБ (минимум 4), 10 ГБ на диске, интернет (~1,2 ГБ скачает
установщик при первой установке).

1. Скачайте `kvazar-setup.exe` из [Releases](../../releases).
2. Запустите. Установщик поставит Квазар и, если нужно, Docker
   Desktop (бесплатная программа, которая запускает Квазар — об этом
   установщик спросит отдельно; может потребовать права
   администратора и одну перезагрузку).
3. После установки откроется мастер первой настройки: название
   организации, ваше имя, email и пароль администратора.
4. Готово — Квазар открывается по адресу http://localhost:8080
   (ярлык уже на рабочем столе). При первом входе система предложит
   настроить двухфакторную аутентификацию (приложение-аутентификатор
   на телефоне) — на это даётся 7 дней.

## Приложение для Windows

Кроме браузера, есть настольное приложение «Квазар»: отдельное окно,
иконка в трее, автозапуск, уведомления Windows. Скачайте
`kvazar-shell-setup.exe` из [Releases](../../releases) и установите;
при первом запуске укажите адрес сервера (обычно
http://localhost:8080). Приложение работает только вместе с сервером
Квазара — если он ещё не установлен, сначала запустите
`kvazar-setup.exe`. Обновляйте приложение повторной установкой.

## Ваши данные

- Всё хранится локально на вашем компьютере.
- Резервные копии создаются ежедневно автоматически; ручной бэкап —
  «Пуск → Квазар → Обновить/Обслуживание» или командой
  `bin\kvazar.cmd backup` в папке установки.
- Ключи шифрования лежат в файле `Документы\Quasar\stack\.env` —
  **сохраните его копию** в надёжном месте: это возможность
  восстановить данные из бэкапа.

## Ограничения беты

- Обновление — повторной установкой поверх (данные сохраняются).
- **Передача/продажа компьютера:** удаление программы НЕ удаляет данные —
  они в базе Docker. Как полностью удалить данные — см. руководство
  (файл box-readme в репозитории продукта или запрос в Support).
- Доступ сотрудников — через браузер по локальной сети
  (http://IP-вашего-компьютера:8080) или в приложении для Windows.
- Удалённый доступ из интернета — в планах (рекомендуем Tailscale).
